How to use a modified Qt build
------------------------------

Section 4 of the LGPLv3 gives the recipient the right to replace the Qt shared
libraries with a modified version and still run the application. That right is
deliberately kept open and needs nothing extra to exercise:

  * every Qt library is an ordinary, unobfuscated DLL in the application's own
    installation folder, and
  * nothing is linked in statically, so no rebuild is required to swap them.

To do it: stop Yozora, replace the Qt6*.dll files (and the files under
plugins\ and translations\) in the installation folder with the ones from your
own Qt build, and start Yozora again.

The application does not check the version or the signature of the Qt libraries
it loads, so a replacement build is picked up without further ceremony.


Bundled typefaces
-----------------

Both families are licensed under the SIL Open Font License 1.1. The OFL permits
bundling and redistribution provided the copyright notice and the licence travel
with the font files, which is why there is one OFL text per family rather than a
single shared one:

    Inter-OFL-1.1.txt          Copyright 2020 The Inter Project Authors
    SpaceGrotesk-OFL-1.1.txt   Copyright 2020 The Space Grotesk Project Authors

The fonts in this distribution are static instances generated by
installer/make_fonts.py. The OFL names the Font Software and its Reserved Font
Names; Yozora does not use them, and the generated files carry only a family
name of "Yozora ..." in name ID 4, so no Reserved Font Name is applied to.

Upstream:
    https://github.com/rsms/inter
    https://github.com/floriankarsten/space-grotesk
