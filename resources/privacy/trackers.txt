# Yozora Browser - built-in tracker blocklist
#
# This is a small, curated list of well known tracking and analytics domains.
# Advertising is handled by the separate ads.txt list; together they are the
# built-in blocker. Like that list this is hand-reviewed rather than a copy of a
# giant public list, so it stays auditable. Only plain domain rules and
# adblock-style "||domain^" rules are understood; any other syntax is ignored.
#
#   domain.com          blocks domain.com and every subdomain of it
#   ||domain.com^       same, in the common filter-list spelling
#   # comment / ! comment
#
# A rule only ever matches the host of a request, never a URL path, so a site
# that both serves content and tracks from the same host cannot be broken by a
# mistake here (and is not listed).
#
# Users may add their own rules in the file "blocklist.txt" next to the browser
# profile (see docs/PRIVACY.md). That file is local only and is never uploaded.
