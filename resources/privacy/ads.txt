# Yozora Browser - built-in advertisement blocklist
#
# Rules here remove advertising, in the spirit of Brave's built-in ad blocking:
# no extension, no subscription, nothing downloaded. Like the tracker list this
# is a small, curated, hand-reviewed set rather than a copy of a giant public
# list, so it stays auditable and cannot break the web in surprising ways.
#
# Supported syntax (everything else is ignored):
#   ||domain.com^          block a domain and every subdomain of it
#   domain.com             the same, in the common plain spelling
#   /path/fragment          block a request whose URL contains this text
#   ...$script,image        restrict a rule to those resource types
#   ...$third-party         restrict a rule to third-party requests
#
# A rule only ever sees the request's URL, host and type; it never inspects page
# content, and a direct navigation the user typed is never blocked.
